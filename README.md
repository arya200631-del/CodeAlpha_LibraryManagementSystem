# CodeAlpha Internship Tasks - Java Programming

This repository contains my task submissions for the CodeAlpha Java Programming Internship.

## 📂 Completed Tasks

*   **Task 1: Hotel Reservation System**
    *   An Object-Oriented Java application to search room categories, make bookings, cancel reservations, and simulate payment workflows.
*   **Task 2: Student Grade Tracker**
    *   A Java program to input and manage student grades, calculate average, highest, and lowest scores, and display a summary report.

## 🚀 How to Run
1. Clone the repository or download the ZIP file.
2. Navigate into the specific task folder.
3. Compile the Java file using `javac FileName.java`
4. Run the program using `java FileName`
